# dev-stack-software.txt
#
# The software list for install-dev-stack.sh. This is the ONLY file you
# need to touch to add, remove, or change a piece of software - the script
# itself (install-dev-stack.sh) never needs to change for that.
#
# One line per tool:
#   name|method|spec|status_pkg|note
#
# Fields:
#   name        display name, shown in --status and log output
#   method      one of: pacman | aur | aur-fragile | mise | custom
#   spec        method-specific "what to install":
#                 pacman        one or more pacman package names, space
#                               separated (installed via omarchy-pkg-add)
#                 aur           one AUR package name (installed via yay,
#                               via omarchy-pkg-aur-add)
#                 aur-fragile   like aur, but known to need manual steps
#                               sometimes - installed the same way as aur,
#                               but a failed build is treated as "needs a
#                               manual step" (marked ACTION NEEDED in
#                               --status) instead of a plain failure. See
#                               step_aur_fragile() in install-dev-stack.sh.
#                 mise          a mise tool@version spec, e.g. java@latest
#                 custom        leave this field empty - custom entries are
#                               wired to a specific function inside
#                               install-dev-stack.sh by their status_pkg
#                               value (see dispatch_custom() there). Adding
#                               a genuinely new bespoke install still means
#                               adding a case + function to the script -
#                               this format only removes the need to edit
#                               the script for anything pacman/AUR/mise can
#                               install, which is nearly everything.
#   status_pkg  the single package/tool name used to look up an installed/
#               available version for the --status table (for custom
#               entries, one of the fixed keys the script recognizes: doom,
#               poly, bws, emacs-daemon, keyd)
#   note        freeform, shown nowhere but here - just for you
#
# Lines starting with # and blank lines are ignored. Don't use literal "|"
# inside any field.
#
# Not sure how to install something new? Run:
#   ./install-dev-stack.sh --check <name>
# It probes pacman, the AUR, and mise for that name and prints a suggested
# line to paste in below.
